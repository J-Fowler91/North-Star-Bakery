# North-Star-Bakery
NORTH STAR BAKERY - TOUCHSTONE 3

Files included:
- index.html
- products.html
- about.html
- contact.html
- styles.css

Before uploading to GitHub:
1. Copy these five files into the same project folder you used for Touchstone 2.
2. Keep your original Bakery_c media files in that folder as well:
   bakery-logo_c.png
   bakery-storefront_c.png
   bakery-bread_c.png
   bakery-signature-loaf_c.png
   bakery-feature-small_c.png
   bakery-feature-large_c.png
   bakery-welcome_c.mp3
   bakery-behind-scenes_c.mp4
3. Open index.html and test all navigation links.
4. Resize the browser below and above 768px to confirm the responsive layout.
5. Push the complete folder to a PUBLIC GitHub repository.
6. Paste the repository URL into the Touchstone 3 design explanation document.

Note: If your media files use .jpg rather than .png, update the matching src/srcset values in the HTML to use the exact filenames from your Bakery_c folder.
